# 校园图书管理系统

这是根据《Python 面向对象高级综合复杂练习》文档实现的完整作业项目。

## 文件说明

- `campus_library_system.py`：主程序，包含所有类设计、业务逻辑和测试演示流程。

## 运行方式

```bash
python3 campus_library_system.py
```

## 已覆盖内容

- `BaseObject`、`Book`、`User`、`Student`、`Teacher`、`BookSystem`
- 类属性、实例属性、类方法、静态方法、实例方法
- 合法借阅、非法借阅、合法归还、非法归还
- 图书统计、用户统计、用户类型统计、分类查找
- 菜单展示与完整流程模拟
