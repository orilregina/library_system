This repository currently contains multiple independent projects.

## New WeChat Mini Program Projects

- `wechat-answer-book-cloud`
  - WeChat cloud development edition
  - No self-hosted server required
  - Includes `miniprogram`, `cloudfunctions`, and launch/checklist documents

- `wechat-answer-book-server`
  - Self-hosted server deployment edition
  - Includes `miniprogram`, `server`, `deploy`, `.env.example`, and launch/checklist documents

## Notes

- The cloud edition is better for individual developers and lightweight launch scenarios.
- The server edition is better if you want a custom Node.js backend and full deployment control.
- Some placeholder values intentionally remain in the project documents, such as AppID, cloud environment ID, formal domain, and operator entity name. Those must be filled with real values before production launch.
