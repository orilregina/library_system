# 云开发版导入与后台配置清单

## 1. 导入项目

微信开发者工具导入这个目录：

```text
C:\Users\wdryyds\Desktop\wechat-answer-book-docs\miniprogram
```

不要导入整个 `wechat-answer-book-docs`。

## 2. 改 AppID

打开：

`miniprogram/project.config.json`

把：

```json
"appid": "touristappid"
```

替换成你的正式小程序 AppID。

## 3. 开通云开发环境

在微信开发者工具顶部打开“云开发”面板：

1. 开通云开发
2. 创建环境
3. 记下环境 ID

## 4. 改云环境 ID

打开：

`miniprogram/utils/config.js`

把：

```js
const CLOUD_ENV_ID = "your-cloud-env-id";
```

替换成你的真实环境 ID。

## 5. 上传云函数

项目内已经有云函数目录：

```text
cloudfunctions/answerBook
```

在微信开发者工具中：

1. 找到云函数 `answerBook`
2. 右键
3. 选择“上传并部署：云端安装依赖”

## 6. 小程序联调

确认以下功能可用：

- 首页输入问题
- 点击“抽取今日卡片”
- 能正常返回卡片结果
- 关于页正常显示
- 隐私页正常显示

## 7. 微信后台配置

登录微信公众平台后完成：

- 配置正式小程序名称
- 配置头像
- 配置简介
- 选择服务类目
- 填写隐私指引

## 8. 提审前最后确认

- `appid` 已替换
- `CLOUD_ENV_ID` 已替换
- 云函数已成功上传部署
- 小程序能正常调用云函数
- 隐私页里的主体名称已替换
- 微信后台隐私指引与页面内容一致
