- 首页、关于页、隐私页已完成

## 还没完成的

- 微信后台隐私指引

### 需要你填入项目

- `miniprogram/project.config.json` 中的 `appid`
- `miniprogram/utils/config.js` 中的 `CLOUD_ENV_ID`
- `miniprogram/pages/privacy/index.wxml` 中的主体名称

### 提审前一定要检查

- `touristappid` 已替换
- `your-cloud-env-id` 已替换
- `待填写运营主体` 已替换
- 云函数 `answerBook` 已上传并部署
- 真机测试能正常调用云函数
- 隐私页内容与微信后台隐私指引一致

## 推荐顺序

1. 获取正式 AppID
2. 开通云开发环境
3. 填入环境 ID
4. 上传部署云函数
5. 联调小程序
