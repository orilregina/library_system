# 你必须准备的信息

以下内容无法由代码自动生成，必须由你或实际运营方准备并填入微信后台或项目配置中。

## 微信后台必须准备

- 正式小程序 AppID
- 小程序名称
- 小程序头像
- 小程序简介
- 服务类目
- 主体认证信息
- 隐私指引内容

## 云开发必须准备

- 云开发环境 ID
- 微信开发者工具中开通该环境
- 云函数上传部署权限

## 项目配置必须准备

- `miniprogram/project.config.json` 中的 `appid`
- `miniprogram/utils/config.js` 中的 `CLOUD_ENV_ID`
- `miniprogram/pages/privacy/index.wxml` 中的运营主体名称

## 提审材料必须准备

- 首页截图
- 抽卡结果截图
- 关于页截图
- 隐私说明截图
- 审核说明文字
- 审核体验路径

## 提交审核前最后确认

- `touristappid` 已替换
- `your-cloud-env-id` 已替换
- `待填写运营主体` 已替换
- 云函数已部署
- 隐私页内容和微信后台隐私指引一致
