# 微信开发者工具云开发逐步点击清单

## 1. 导入项目

1. 打开微信开发者工具
2. 点击“导入项目”
3. 目录选择：

```text
C:\Users\wdryyds\Desktop\wechat-answer-book-cloud\miniprogram
```

4. 项目名称可填写“月影答案书”
5. `AppID` 先填写你的正式小程序 AppID
6. 点击“导入”

## 2. 检查项目配置

1. 在左侧文件树打开 `miniprogram/project.config.json`
2. 确认 `appid` 已替换，不再是 `touristappid`
3. 打开 `miniprogram/utils/config.js`
4. 把：

```js
const CLOUD_ENV_ID = "your-cloud-env-id";
```

替换成你的真实云开发环境 ID

## 3. 开通云开发环境

1. 在开发者工具顶部点击“云开发”
2. 如果还没开通，点击“开通”
3. 选择环境创建方式
4. 创建环境后记下环境 ID
5. 返回代码，把这个环境 ID 写入 `miniprogram/utils/config.js`

## 4. 上传并部署云函数

1. 在左侧找到 `cloudfunctions/answerBook`
2. 右键 `answerBook`
3. 点击“上传并部署：云端安装依赖”
4. 等待状态完成
5. 部署成功后，在云开发控制台确认 `answerBook` 已上线

## 5. 本地预览联调

1. 回到小程序首页
2. 在输入框输入一个问题
3. 点击“抽取今日卡片”
4. 如果正常返回卡片结果，说明云函数调用成功
5. 再检查：
   - 关于页
   - 隐私页
   - 清空记录

## 6. 真机预览

1. 点击开发者工具顶部“预览”
2. 用微信扫码真机打开
3. 再次测试抽卡、结果展示、关于页、隐私页

## 7. 上传体验版

1. 点击顶部“上传”
2. 填版本号，例如 `1.0.0`
3. 填版本备注
4. 上传成功后，在微信公众平台查看体验版

## 8. 微信公众平台后台

登录 [mp.weixin.qq.com](https://mp.weixin.qq.com) 后完成：

1. 设置正式小程序名称
2. 设置头像
3. 设置简介
4. 选择服务类目
5. 填写隐私指引
6. 确认主体信息

## 9. 提交审核前最后确认

1. `AppID` 已替换
2. `CLOUD_ENV_ID` 已替换
3. 云函数 `answerBook` 已部署
4. 隐私页中的运营主体名称已替换
5. 关于页、隐私页、首页都无占位内容
6. 真机测试通过
7. 截图和审核说明已准备好
