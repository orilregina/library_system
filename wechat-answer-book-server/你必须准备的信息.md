# 你必须准备的信息

以下内容无法由代码自动生成，必须由你或实际运营方准备并填入微信后台或项目配置中。

## 微信后台必须准备

- 正式小程序 AppID
- 小程序名称
- 小程序头像
- 小程序简介
- 服务类目
- 主体认证信息
- 隐私指引内容
- 合法 request 域名

## 服务器必须准备

- 正式 API 域名
- 云服务器
- HTTPS 证书
- 服务器登录权限
- 域名备案信息（如适用）

## 项目配置必须准备

- `COMPANY_NAME`
- `CONTACT_EMAIL`
- `CONTACT_PHONE`
- `PUBLIC_BASE_URL`
- `miniprogram/project.config.json` 中的 `appid`
- `miniprogram/utils/config.js` 中的 `trial` / `release` 域名

## 提审材料必须准备

- 首页截图
- 抽卡结果截图
- 关于页截图
- 隐私说明截图
- 审核说明文字
- 审核体验路径

## 提交审核前最后确认

- 所有 `example.com` 已替换
- 所有 “待填写” 占位信息已替换
- `/api/launch-check` 返回 `ready: true`
- 微信后台合法域名已配置
- 隐私页内容和微信后台隐私指引一致
