# 微信小程序提审文案参考

## 小程序名称

月影答案书

## 一句话简介

一款深夜蓝塔罗绘画风格的灵感卡牌互动工具。

## 功能介绍

月影答案书提供轻量的卡牌抽取体验。用户可以输入一个当下的问题，点击抽取按钮后获得一张象征卡片、关键词和一句灵感解释。小程序支持查看最近的本机抽取记录，并可手动清空。

本产品用于娱乐互动、情绪整理和自我复盘，不提供医疗、心理、法律、投资等专业建议，也不承诺预测未来。

## 审核员体验路径

1. 进入首页。
2. 在输入框中输入问题，例如“我今天应该把注意力放在哪里？”。
3. 点击“抽取今日卡片”。
4. 查看卡片结果、关键词和解释。
5. 可进入“关于月影答案书”和“隐私说明”页面查看说明。

## 隐私说明摘要

小程序不会主动读取手机号、通讯录、位置、相册、麦克风等敏感权限。用户输入的问题仅用于生成本次卡片结果。最近记录保存在用户设备本地，用户可在首页清空。服务端如保留请求记录，应仅用于排查服务问题，并按照正式隐私指引说明保存周期和删除方式。

## 类目建议

请以微信公众平台当前可选类目和主体资质为准。建议优先选择与“工具、娱乐互动、生活服务、内容展示”相关的类目，避免使用高风险的“占卜、算命、预测”表述。
