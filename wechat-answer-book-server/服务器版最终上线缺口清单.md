# 服务器版最终上线缺口清单

## 已经准备好的

- 小程序前端页面结构已完成
- 首页、关于页、隐私页已具备基础提审文案
- Node.js 后端接口已完成
- PM2 配置已完成
- Nginx 配置示例已提供
- `.env.example` 已提供
- `npm run check:server` 可做语法检查
- `npm run check:launch` 可做上线配置检查

## 还没准备好的

以下是当前服务器版真正上线前仍未完成的内容。

### 必须由你准备

- 正式小程序 AppID
- 运营主体名称
- 正式 API 域名
- 云服务器
- HTTPS 证书
- 微信公众平台类目
- 微信公众平台简介与头像
- 微信后台合法 request 域名
- 微信后台隐私指引

### 需要你填入项目

- `miniprogram/project.config.json` 中的 `appid`
- `miniprogram/utils/config.js` 中的 `trial` / `release`
- `.env` 中的 `PUBLIC_BASE_URL`
- `.env` 中的 `COMPANY_NAME`
- 如有变化，隐私页中的主体名称

### 上线前一定要检查

- `touristappid` 已替换
- `api.example.com` 已替换
- `待填写运营主体` 已替换
- 微信后台合法域名与代码里的正式域名一致
- 隐私页内容与微信后台隐私指引一致
- `npm run check:launch` 返回通过
- `GET /api/launch-check` 返回 `ready: true`

## 推荐上线顺序

1. 先拿到小程序正式 AppID
2. 准备正式域名、服务器和证书
3. 创建正式 `.env`
4. 部署 Node 服务和 Nginx
5. 用开发者工具联调真实接口
6. 配置微信后台合法域名和隐私指引
7. 上传体验版
8. 真机测试
9. 提交审核

## 当前最短阻塞项

你现在最短板的不是代码，而是真实配置值：

- AppID
- 正式 API 域名
- 运营主体名称

没有这三项，服务器版无法进入真正的提审完成态。
